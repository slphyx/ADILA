# Antibiotic Data to Inform Local Action (ADILA)

ADILA – Antibiotic Use Estimator

ADILA is an online tool designed to estimate expected empirical antibiotic use in hospitals on any given day. The model assumes empirical prescriptions follow guidance from The WHO AWaRe (Access, Watch, Reserve) Antibiotic Book.

🔍 What ADILA Does

ADILA generates an estimate of anticipated empirical antibiotic use based on:

- Local patient numbers and infection types
- Infection severity
- Availability of first-choice antibiotics
- Local antimicrobial resistance (AMR) patterns across pathogens

These estimates help hospitals understand expected antibiotic needs, support stewardship decisions, and align with WHO AWaRe recommendations.

🚀 Features

- Input local assumptions and data to model expected empirical antibiotic use
- Categorizes antibiotic use by Access, Watch, and Reserve groups
- Provides quick, scenario-based estimation for stewardship and planning
- Simple, browser-based tool

📖 Background

Expected use refers to the anticipated empirical antibiotic consumption derived from local epidemiology and assumptions about clinical practice. ADILA supports hospitals in comparing expected vs. observed antibiotic use to identify potential stewardship opportunities.
